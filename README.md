# Система для видеоанализа очереди
Данный репозиторий содержит прототип решения для анализа очереди.
Зависимости, которые требуется удовлетворить, используя pip:
* ultralytics (для YOLO)
* PyTorch
* shapely
* numpy
* cv2 (opencv)
* sk-learn

## Файлы, представленные в репозитории
* solution.py - скрипт, осуществляющий анализ видеопотока (только очереди).
* solution\_with\_staff.py - скрипт, осуществляющий анализ видеопотока (очереди и персонала).
* solution\_with\_staff\_time.py - скрипт, осуществляющий анализ видеопотока (очереди и персонала), с рассчётом времени ожидания исходя из среднего времени пребывания в очереди.
* solution\_with\_staff\_speed.py - скрипт, осуществляющий анализ видеопотока (очереди и персонала), с рассчётом времени ожидания исходя из средней скорости человека в очереди (корректно только после калибровки).
* plot.py - скрипт для вывода графика зависимости количества людей в очереди от времени.
* plot\_mean\_time.py - скрипт для вывода графика среднего времени ожидания.
* annotate\_manual.py - скрипт для удобной разметки обучающего набора изображений подносов.
* quality.py - скрипт для разделения данных для удобной оценки качества распознавания подносов.
* predict\_load.py - скрипт для создания и использования предсказательной модели для оценки загрузки в данный час.
* predict\_load\_day.py - скрипт для создания и использования предсказательной модели для оценки распределения загрузки на целый день с учётом ориентировочного количества людей за день суммарно.
* examples/ - директория, в которой представлено использование скрипта на предоставленных видеозаписях.
  * cameras/ - директория, содержащая настройки многоугольников отдельно для двух данных ракурсов камер.
  * videos/ - директория, содержащая предоставленные видео. Видео разделены по ракурсам и находятся в двух директориях cam1/ и cam2/.
  * results/ - директория, содержащая результат анализа предоставленных видео. Видео разделены по ракурсам и находятся в двух директориях cam1/ и cam2/.
  * screenshots/ - директория, содержащая снимки, сделанные во время анализа видео.
